# ANNS Healthy Wealthy Corporate Solutions - Temporary Static Website

This is a simple static website suitable for GitHub Pages and for linking from Meta Business Suite.

## Files
- `index.html`
- `styles.css`
- `script.js`
- `logo.svg`

## Before publishing
Open `index.html` and replace:

`YOUR-EMAIL@example.com`

with the actual business email address.

You can also change the text, service list, contact details and logo later.

## Publish with GitHub Pages
1. Create a new GitHub repository, for example:
   `anns-healthy-wealthy-corporate-solutions`
2. Upload all files in this folder to the repository root.
3. Open the repository on GitHub.
4. Go to **Settings → Pages**.
5. Under **Build and deployment**, choose:
   - Source: **Deploy from a branch**
   - Branch: **main**
   - Folder: **/ (root)**
6. Save.
7. GitHub will give you a public URL such as:
   `https://yourusername.github.io/anns-healthy-wealthy-corporate-solutions/`
8. Use that URL temporarily in Meta Business Suite.

## Recommended later
When your permanent domain is ready, connect it to the same site or replace this temporary site with your full business website.
